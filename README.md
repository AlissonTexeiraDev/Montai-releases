# Montai — instaladores do beta

Este repositório guarda só os instaladores do **Montai**, o editor de vídeo com IA. O código fica em um repositório privado.

**Baixar:** abra [Releases](https://github.com/AlissonTexeiraDev/Montai-releases/releases/latest) e baixe o `Montai-Setup-…exe` mais recente.

- Windows 10 ou 11 (64 bits); recomendado 16 GB de RAM.
- O Windows pode avisar "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. O instalador ainda não tem assinatura digital.
- Depois de instalado, o Montai se atualiza sozinho.

Achou um problema ou teve uma ideia? Use o botão de feedback no topo do app e mande o relatório no grupo do beta.
